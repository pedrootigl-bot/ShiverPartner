# LogoLoop — plataformas sociais

## Objetivo

Faixa de logos em loop logo após a seção `PartnerProgram`, com YouTube, Instagram e TikTok.

## Arquivos

- `src/components/LogoLoop.jsx` / `LogoLoop.css`
- `src/components/SocialLogoLoop.jsx` / `SocialLogoLoop.css`
- Dependência: `react-icons`

## Configuração

- Logos: YouTube, Instagram, TikTok
- `fadeOutColor`: `#070812` (fundo do site)
- `speed`: 90 · `hoverSpeed`: 0 · `scaleOnHover`: true
